# Dobbelen met Regenboog

Een eenvoudig dobbelspel voor groep 1-2.

- Klik op **Gooi maar** of op de dobbelsteen om te gooien.
- De pijl wisselt met een magisch effect tussen blije en angstige Regenboog.
- Blij: de volgende worp is 1–3. Angstig: de volgende worp is 1–6.
- De vorige worp blijft staan wanneer de vis verandert.

Open `index.html` in een browser. Illustraties en achtergrond zijn lokaal ingesloten.
